### 1. **Estimating an Object’s Inertial Parameters by Robotic Pushing: A Data-Driven Approach**

* **Category**:
  Q3 — **Data-driven Payload Identification**
  (focus on object inertial parameter estimation through robotic pushing and system identification using data-driven methods).

* **Problem/Issue**:
  Traditional inertial parameter identification requires restrictive setups (e.g., force/torque sensors, precise grasp). This work aims to estimate inertial properties (mass, center of mass, friction) via **pushing interactions** and data-driven learning.

* **Math Background**:

  * **Rigid-body planar pushing dynamics**: contact forces + friction cone modeling.
  * Linearized regression for inertial parameters.

* **Methods**:

  * Collect motion data from robotic pushing experiments.
  * Learn object parameters from observed motions using **data-driven identification** (regression-based).
  * Compare performance with analytic model-based estimation.

* **Results**:

  * Demonstrates that pushing can recover approximate inertial parameters without force sensors.
  * Robust under model uncertainties and unstructured contacts.
  * Experimental validation with tabletop pushing tasks.

* **Contribution**:

  * Proposes **contact-rich, data-driven approach** to identify inertial parameters.
  * Removes dependency on precise grasp or force sensing.
  * Opens a path for general object ID during manipulation via interaction.

### 2. **Model-based Reinforcement Learning with Parametrized Physical Models and Optimism-Driven Exploration**

(Xie, Patil, Moldovan, Levine & Abbeel, UC Berkeley)

* **Category**:
  Q5 — **Learning-Based System Identification**
  (combines physics-based models with reinforcement learning and optimistic exploration).

* **Problem/Issue**:
  RL often requires huge data; model-based RL can be efficient but suffers from poor dynamics modeling. Need a method that integrates **physical knowledge** + **exploration strategy** for robotic control.

* **Math Background**:

  * Equations of motion:
    [
    M(q)\ddot{q} + C(q,\dot{q}) + g(q) = \tau
    ]
    written in **linear-in-parameters form** for identification.
  * **Least squares fitting** of unknown inertial parameters.
  * **Optimism-driven exploration** in MPC framework.

* **Methods**:

  * **Feature-based regression**: uses morphology knowledge (links, connectivity).
  * Online **least-squares identification** of parameters.
  * **Optimistic Model Predictive Control (MPC)**: balances exploration/exploitation.

* **Results**:

  * Outperforms PILCO and Gaussian Process baselines on pendulum, cartpole, double pendulum.
  * Achieves **real-time learning control** on a simulated 7-DoF Barrett WAM arm.
  * Faster adaptation to new dynamics with fewer samples.

* **Contribution**:

  * First integration of **parametrized physical models** with **optimism-driven exploration**.
  * Shows **sample-efficient RL** with real robotic morphology priors.
  * Demonstrates scaling from simple systems to high-DoF robotic arms.

### 3. **Preparing for the Unknown: Learning a Universal Policy with Online System Identification** (Yu, Tan, Liu & Turk, RSS 2017)

* **Category**:
  Q5 — **Physics-Informed / Differentiable**
  (Couples reinforcement learning with parameterized dynamic models + online system identification.)

* **Problem/Issue**:
  Deep RL policies trained in simulation often fail in the real world due to the **Reality Gap** (unmodeled parameters like mass, friction, actuator latency). Need policies that generalize across unknown dynamics.

* **Math Background**:

  * Dynamic system parameterized by µ:
    [
    x_{t+1} = f_\mu(x_t, u_t)
    ]
  * Universal Policy (UP):
    [
    \pi(x, \mu) \to u
    ]
  * Online System Identification (OSI): supervised learning of
    [
    \phi(x_{t-h:t}, u_{t-h:t-1}) \to \mu
    ]

* **Methods**:

  * **Universal Policy (UP):** trained over wide distribution of simulated dynamics.
  * **Online System Identification (OSI):** neural network predicts dynamics parameters from recent state-action history.
  * Training: iterative TRPO + supervised learning, with “good” and “bad” rollouts to improve OSI robustness.

* **Results**:

  * Benchmarks: **double inverted pendulum**, **robotic manipulator block-throwing**, **hopper locomotion**, **cart-pole swing-up**.
  * UP-OSI adapts online to varying mass, CoM, pole length, and friction.
  * **Generalizes beyond training range**, outperforms UP alone and sometimes UP with ground-truth parameters.

* **Contribution**:

  * First integration of **online system identification with a universal policy** in deep RL.
  * Achieves **robust adaptive control under unknown and time-varying dynamics**.
  * Promises better transfer from simulation to real-world robots.

### 4. **Learning Force Control for Contact-Rich Manipulation Tasks With Rigid Position-Controlled Robots**

(Beltran-Hernandez et al., IEEE RAL 2020)

* **Category**:
  Q3 — **Reinforcement Learning + Force Control**
  (Focus on combining RL with classical force/admittance controllers for industrial rigid robots.)

* **Problem/Issue**:
  RL is powerful for manipulation but unsafe on **rigid position-controlled robots**, which dominate industry. These robots cannot directly apply torque control, making force-sensitive tasks (e.g., assembly) difficult.

* **Math Background**:

  * Force control laws:

    * **Parallel Position/Force control**
    * **Admittance control**
  * RL agent learns control gains and trajectories under contact forces.

* **Methods**:

  * Proposed a **learning-based force control framework** combining RL with traditional controllers.
  * Two schemes tested: modified parallel position/force and admittance control.
  * Developed a **fail-safe mechanism** for safe online RL training on hardware.

* **Results**:

  * Validated in **simulation and real UR3e robot**.
  * RL agent learned safe and efficient contact-rich behaviors.
  * Framework allowed tuning of compliant controllers directly via RL.

* **Contribution**:

  * First integration of RL with force control for **rigid position-controlled robots**.
  * Safe training method that makes RL feasible on real hardware without torque-level access.
  * Demonstrated potential for **contact-rich industrial tasks** (assembly, force-sensitive operations).

### 5. **Reinforcement Learning Based Variable Impedance Control for High Precision Human-Robot Collaboration Tasks**

(Meng, Su & Wu, IEEE ICARM 2021)

* **Category**:
  Q3 — **Reinforcement Learning + Variable Impedance Control**
  (Model-free RL to adapt impedance parameters for collaborative assembly.)

* **Problem/Issue**:
  Human-robot collaboration requires **adaptivity to different human operators** and tasks. Fixed impedance controllers are not sufficient for high-precision assembly.

* **Math Background**:

  * Impedance control law with variable parameters (inertia, damping, stiffness).
  * RL optimization via **Proximal Policy Optimization (PPO)**.

* **Methods**:

  * Designed a **Variable Impedance Learning Control (VILC)** strategy.
  * RL agent outputs impedance parameters in real time.
  * PPO ensures stable training and adaptation.

* **Results**:

  * Tested in human-robot collaboration **assembly tasks**.
  * Robot adapted impedance online to operator differences.
  * Achieved robust, precise assembly with reduced training data.

* **Contribution**:

  * First PPO-based variable impedance framework for collaborative assembly.
  * Teach-less approach — no need for demonstrations.
  * Generalizable across different operators and conditions.
