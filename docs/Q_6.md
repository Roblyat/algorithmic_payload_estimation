### 1. **Tactile-Driven Dexterous In-Hand Writing via Extrinsic Contact Sensing** (RA-L 2025)

* **Problem/Issue**: In-hand manipulation requires precise contact force sensing. Standard tactile sensors have limited coverage → difficult to generalize to dexterous tasks like writing.

* **SoA**: Reinforcement learning with tactile inputs; extrinsic sensors improve generalization.

* **Math Background**: Policy learning via RL, tactile sensing as state features, trajectory optimization.

* **Methods**:

  * Extrinsic tactile sensing (contact sensors outside the hand).
  * RL framework learns dexterous writing policy.
  * Adaptation to variability in handwriting and surfaces.

* **Results**: Achieved robust in-hand writing on surfaces, adapting to contact dynamics.

* **Contribution**: Demonstrates extrinsic tactile sensing + RL for **dexterous in-hand tasks**.

* **Outlook**: Generalize to broader in-hand manipulation (tool use, assembly).

* **Focus**: **Contact/task adaptation**, not payload ID.

### 4. **Contact Localization for Robot Arms in Motion without Torque Sensing** (ICRA 2021)

* **Problem/Issue**: Contact localization usually requires torque sensing.

* **SoA**: Contact particle filter, SVM classifiers, ML models with proprioception.

* **Math Background**: Domain randomization, convolutional neural networks, cylindrical projection encoding.

* **Methods**:

  * Neural network trained with domain randomization.
  * Cylindrical projection encoding → convolutional feature extraction.
  * Predicts contact points as distance fields.

* **Results**: 91.5% detection accuracy, 3.0 cm localization error.

* **Contribution**: Enables contact localization without torque sensors.

* **Outlook**: Extend to multi-contact, cluttered environments.

* **Focus**: **Contact localization via proprioception**.

### 6. **Payload Parameters Identification Using Incremental Ensemble Learning** (ICCCR 2024)

* **Problem/Issue**: Classical and batch ensemble ID require excitation trajectories, slowing cobot reconfiguration. Need fast online payload ID adaptable to arbitrary paths.

* **SoA**: RLS-based model ID, SVM regression, batch ensemble (NN + DT) for payloads, but limited to excitation paths.

* **Math Background**: Inertial parameter vector φ = \[m, m·r, I]; stochastic gradient descent (SGD) for incremental training.

* **Methods**:

  * Incremental ensemble (5 weak learners = single-layer NNs).
  * Classification process checks whether new trajectory data lies inside prior training space.
  * If not → incremental learning step updates weak learner online.

* **Results**:

  * MAE: 0.01 kg (mass), 0.0068 kg·m (CoM), 0.0008 kg·m² (inertia).
  * Effective without excitation trajectory, adapts during arbitrary task execution.

* **Contribution**: First IEM approach to remove excitation path requirement in payload ID.

* **Outlook**: Scaling to heavier payloads, more complex trajectories, real-time deployment in factories.

* **Focus**: **Online payload inertial parameter identification**.

### 7. **Online Identification of Payload Inertial Parameters Using Ensemble Learning for Collaborative Robots** (RA-L 2024)

* **Problem/Issue**: Collaborative robots require online payload parameter estimation for safety, but existing observers degrade under dynamic changes and uncertainties.

* **SoA**: Classical inverse dynamics + observers, batch ensemble learning, incremental ensemble learning (early).

* **Math Background**: Rigid body dynamics, ensemble model theory, payload inertial parameter vector φ.

* **Methods**:

  * Ensemble learning model with weak learners.
  * Online update using cobot proprioception (joint torque, motion).
  * Real-time adaptation during arbitrary collaborative tasks.

* **Results**:

  * Ensemble method improves estimation robustness vs. classical ID.
  * Demonstrated on collaborative robot platforms with online adaptation.

* **Contribution**: Demonstrates feasibility of **ensemble learning for online payload inertial ID** in collaborative robotics.

* **Outlook**: Extend to adaptive/continual learning frameworks, benchmark on diverse cobot tasks.

* **Focus**: **Online payload inertial parameter identification for cobots**.

### 8. **Addressing Catastrophic Forgetting in Payload Parameter Identification Using Incremental Ensemble Learning** (Frontiers in Robotics and AI, 2024)

* **Problem/Issue**: Prior IEM approach (Taie et al. 2024, ICCCR) still suffered from catastrophic forgetting when updated with new data.

* **SoA**: Classical RLS, batch ensemble, incremental ensemble (IEM). Forgetting is a well-known continual learning issue.

* **Math Background**: Ensemble learning theory, incremental weak learners (single-layer NN), SGD optimization, classification via Euclidean distance thresholds.

* **Methods**:

  * Novel IEM that **adds a new weak learner per new training bag**.
  * Classification model assigns inputs to the most accurate learner.
  * Maintains accuracy on old learners after updates.

* **Results**:

  * Eliminates catastrophic forgetting.
  * MAE \~0.007 kg on mass estimation; robust across old and new task paths.
  * Validated on Franka Emika Panda with variable payloads.

* **Contribution**: First cobot payload ID approach to explicitly solve catastrophic forgetting.

* **Outlook**: Extend to long-term continual learning with many tasks, explore hybrid GP/DL ensembles.

* **Focus**: **Incremental ensemble payload ID without catastrophic forgetting**.


### 9. **External force estimation for robotic manipulator based on particle swarm optimization.** (Liu et al IJARS 2021)

* **Problem/Issue**:
  Sensor-based force estimation is costly and unreliable in harsh environments (e.g., nuclear).

* **SoA**:

  * Least-squares (LS) methods, ML-based identification, heuristic optimization.
  * Problems: ill-conditioning, local optima.

* **Math Background**:

  * Newton–Euler dynamics with joint friction.
  * Parameter identification via **particle swarm optimization (PSO)**.

* **Methods**:

  * Optimized excitation trajectories.
  * Compared PSO with biogeography-based optimization and cuckoo search.
  * Identified dynamics → used for **sensorless external force estimation**.

* **Results**:

  * Kinova Jaco2 manipulator experiments.
  * RMS error of 0.7 N in force estimation.
  * PSO superior to other heuristics.

* **Contribution**:

  * First integration of **PSO-based parameter ID** for sensorless external force estimation.

## 🔎 Conclusion of Q₆ Research (Domain Adaptation / Latent Context)

### 1. **Scope Covered**

* Covers **domain adaptation, sim-to-real transfer, cross-modal perception, tactile-driven adaptation, and MPC with simulation**.
* All papers focus on **adapting policies or perception across domains or modalities**.

### 2. **What They Estimate**

* **Robot internal/contact adaptation**: torque-free contact localization, adaptive motion control.
* **Payload/object recognition**: cross-modal (vision ↔ tactile).
* **Policy adaptation**: sim-to-real bolting, tactile-driven RL, MPC.

### 3. **Mathematical Backbone**

* Domain randomization, transfer learning, reinforcement learning.
* Neural architectures (CNNs with cylindrical projections).
* MPC + physics-informed simulation.
* Multimodal point cloud alignment (MLS, voxel filtering).

### 4. **State of the Art Trend**

* Moving from **direct parameter estimation** → toward **robustness via adaptation**.
* Focus on **safety and real-world applicability**: sim-to-real, tactile robustness, torque-free sensing.
* Multimodal transfer (vision ↔ touch) is an emerging frontier.

### 5. **Overall Coverage**

* **Robot internal adaptation**: control precision, contact localization.
* **Payload/object recognition**: visuo-tactile transfer.
* **Policy-level adaptation**: sim-to-real, RL adaptation, MPC.

✅ **Conclusion**:
Q₆ research does not focus on estimating explicit inertial/payload parameters, but instead on **ensuring estimators and policies generalize across domains, modalities, and uncertainties**. This is crucial for real-world deployment of the estimation pipelines from Q₁–Q₅.
