## 1. **Fast Object Inertial Parameter Identification for Collaborative Robots**&#x20;

* **Problem/Issue**: Collaborative robots (cobots) need to identify object inertial parameters (mass, CoM, inertia tensor) quickly. Low SNR in safe cobot regimes makes existing identification slow/inaccurate.
* **SoA**: Classic methods = LS, RTLS, manifold optimization. But they suffer from noise and ill-posedness.
* **Math Background**: Rigid body dynamics, approximation of dynamics, point mass discretization (PMD) to approximate inertia. Uses error metrics invariant to mass/size.
* **Methods**:

  * Approximate dynamics to boost SNR.
  * Discretize shape into point masses for fast plausible inertia estimation.
  * Benchmarked vs OLS, RTLS, GEO.
* **Results**: PMD significantly faster, robust under noise. Loses identifiability of full inertia tensor, but good trade-off. Experiments on modular test objects confirm performance.
* **Contribution**: A method tailored for cobot regime, fast enough for online use.
* **Outlook**: Extend to combine with physical consistency constraints, explore hybrid with learning.

## 2. **Online Payload Identification for Tactile Robots Using the Momentum Observer**&#x20;

* **Problem/Issue**: Payload affects safety, control, and collision detection. Need *online payload ID* during task execution.
* **SoA**: LS / RLS dominate payload ID; RTLS/quaternion filters exist, usually need sensors (F/T, IMU). Observer-based methods emerging.
* **Math Background**: Momentum observer theory, LS estimation, filtering of kinematics, calibration with virtual object.
* **Methods**:

  * Use torque estimates from momentum observer.
  * Novel filter design to align acceleration signals.
  * Introduce *virtual calibration object* to improve model online.
* **Results**: Tested on Franka Emika Panda. Novel method reduced error compared to baseline filtering. Calibration step improves robustness to trajectory mismatch.
* **Contribution**: First integration of momentum observer torque estimates into online payload ID. Practical calibration strategy.
* **Outlook**: Broaden to dynamic tasks, extend calibration beyond single trajectories.

## 3. **External Torque Estimation Using Higher Order Sliding-Mode Observer for Robot Manipulators**&#x20;

* **Problem/Issue**: Robots in contact tasks need external torque/force estimates robust to nonlinear friction & model errors.
* **SoA**: Prior ESO (extended state observer) methods lack robustness; Luenberger observers used, but limited stability guarantees.
* **Math Background**: Sliding-mode control/observers, Lyapunov stability, SOS programming for observer design.
* **Methods**:

  * Higher-order sliding mode observer for torque.
  * Luenberger observer to stabilize momentum error dynamics.
  * SOS & Lyapunov-based proofs.
* **Results**: Validated on Sawyer 7-DOF manipulator. Showed convergence of torque estimates, robustness to 5% model error, superior to ESO.
* **Contribution**: Robust real-time torque observer with stability proofs.
* **Outlook**: Extend to force estimation in more complex uncertain dynamics, integration into physical human-robot interaction.

## 4. **Contact Force and Torque Sensing for Serial Manipulator Based on an Adaptive Kalman Filter**&#x20;

* **Problem/Issue**: Force/torque sensors are costly and fragile. Need sensorless estimation of contact forces/torques.
* **SoA**: Generalized momentum observer (De Luca) widely used, but suffers from noise in current-based estimation.
* **Math Background**: Kalman filtering, adaptive covariance tuning, generalized momentum models.
* **Methods**:

  * Adaptive Kalman filter (AKF) with variable time window.
  * Mode-switching moving average (MSMA) to reduce motor current noise.
  * Applied to UR5 manipulator.
* **Results**: Achieved reduced error & faster response vs pioneering methods. Robust even with payload variation.
* **Contribution**: Practical, low-cost alternative to 6-axis F/T sensors.
* **Outlook**: Extend AKF to more nonlinear settings, integrate with disturbance observers.

## 5. **The Sum of Its Parts: Visual Part Segmentation for Inertial Parameter Identification of Manipulated Objects**&#x20;

* **Problem/Issue**:
  Collaborative robots must identify object inertial parameters (mass, CoM, inertia tensor) safely. Traditional methods require fast, dynamic motions → unsafe for cobots (ISO safety limits). Need robust parameter ID from *slow or stop-and-go motions*.

* **State of the Art**:

  * LS/RTLS approaches sensitive to low SNR.
  * Constrained optimization ensures physical consistency.
  * Recent geometric approaches (e.g., geodesic-based) still sensitive to noise.
  * Noisy FT sensor data limits accuracy.

* **Mathematical Background**:

  * Assumption: objects consist of homogeneous-density parts.
  * Parameter ID reduces to estimating the *mass of each homogeneous part*.
  * Formulated as convex optimization:

    $$
    \min_m ||Am - b||^2 \quad \text{s.t. } m_j \geq 0
    $$
  * Inertial tensor/CoM computed from tetrahedralized point-cloud shape.

* **Methods**:

  * **Homogeneous Part Segmentation (HPS)** = combine vision (RGB-D) + FT sensing.
  * Surface-based clustering + volumetric tetrahedral segmentation (HTC).
  * Initial clustering accelerates HTC (3× faster).
  * Shape reconstruction from point clouds (ball-pivoting).
  * Dataset of 20 segmented workshop tools (open source).

* **Results**:

  * Outperforms OLS (least squares) and GEO (geodesic optimization) in noisy scenarios.
  * Real cobot demo: hammer balancing using identified inertial parameters.
  * Errors: OLS often inconsistent; GEO stable but dependent on strong prior. HPS achieves better CoM and inertia estimation under noise.

* **Contribution**:

  * First integration of visual segmentation + FT data for cobot-safe inertial parameter ID.
  * New dataset for benchmarking.
  * Open-source code and data.

* **Outlook**:

  * Extend to mixed-integer programming with material priors (density lists).
  * Improve segmentation so parts’ centroids are not coplanar.
  * Handle multi-part articulated objects.
